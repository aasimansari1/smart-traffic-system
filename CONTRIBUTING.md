# Contributing to smart-traffic-system

Thanks for your interest in contributing! Contributions of all kinds are welcome — bug reports, feature ideas, docs, and code.

## Getting Started

1. **Fork** this repository and **clone** your fork.
2. Create a branch: `git checkout -b feature/your-feature`.
3. Install dependencies (see the README for setup).
4. Make your changes with clear, focused commits.

## Pull Requests

- Keep PRs small and scoped to a single change.
- Describe **what** changed and **why** in the PR description.
- Reference any related issue (e.g. `Closes #12`).
- Ensure the project still runs and existing checks pass.

## Reporting Issues

Open an issue with:
- What you expected vs. what happened
- Steps to reproduce
- Environment (OS, Python/Node version)

## Code Style

- Keep code readable and consistent with the surrounding style.
- Add comments only where intent isn't obvious.

## Code of Conduct

Be respectful and constructive. We want this to be a welcoming project for everyone.
